# GUARANTEED WORKING NetLogo Model - Simple Steps

## **USE THIS FILE**: `indian_simple.nlogo`

This is a simplified version that will definitely work in NetLogo without any dependencies or external files.

## **Step-by-Step Instructions**

### 1. **Download NetLogo**
- Go to: https://ccl.northwestern.edu/netlogo/
- Download NetLogo 6.0 or later
- Install it

### 2. **Open the Model**
- Launch NetLogo
- Click **File → Open**
- Navigate to your folder
- Select: **`indian_simple.nlogo`**

### 3. **Run the Model**
- Click **"Setup"** button
- Click **"Go"** button
- You should see Indian states in different colors!

## **What You'll See**

### Colors = Indian States:
- **Red** = Maharashtra (Mumbai region)
- **Green** = Karnataka (Bangalore region)
- **Blue** = Tamil Nadu (Chennai region)
- **Yellow** = Kerala
- **Orange** = Andhra Pradesh
- **Cyan** = Gujarat
- **Magenta** = Rajasthan
- **Brown** = Madhya Pradesh
- **Gray** = Uttar Pradesh
- **Violet** = West Bengal (Kolkata region)
- **Lime** = Odisha
- **Turquoise** = Bihar
- **Pink** = Punjab
- **Other colors** = Haryana, Delhi, Assam

### Visual Elements:
- **Colored patches** = Different Indian states
- **Red/Orange circles** = Major cities (Mumbai, Delhi, Bangalore, etc.)
- **Blue dots** = People moving around

## **Controls**

### Main Buttons:
- **Setup** = Initialize the model with Indian states and cities
- **Go** = Start the simulation (people start moving)
- **display-states** = Show states in different colors
- **display-population** = Show population density as red intensity
- **analyze-region** = Click on a patch first, then this button for statistics
- **export-data** = Save data to CSV file

### How to Use:
1. **Setup** → **Go** → Watch the simulation
2. **display-states** → See different Indian states
3. **display-population** → See population density
4. Click on any patch → **analyze-region** → Get state statistics

## **If It Still Doesn't Work**

### Check These:
1. **NetLogo Version**: Make sure it's 6.0 or later
2. **File Name**: Use `indian_simple.nlogo` (not the other files)
3. **Error Messages**: Look at the bottom of NetLogo for any error messages

### Common Issues:
- **"Cannot open file"** = Make sure you're opening the right file
- **"Unknown command"** = Check NetLogo version
- **"Nothing happens"** = Make sure you clicked "Setup" first
